# Tesis Digital - Biología: Microevolución

## Descripción

Este repositorio contiene una **tesis digital interactiva** sobre biología evolutiva, específicamente enfocada en la **microevolución**. Fue diseñada como recurso educativo para estudiantes de secundaria (aproximadamente 14 años), con un enfoque didáctico, visual y accesible.

## Contenido

La tesis digital incluye las siguientes secciones:

1. **Introducción a la microevolución** - Definición, conceptos básicos (población, gen, alelo, frecuencia alélica, fenotipo)
2. **Genética de poblaciones y el acervo génico** - Acervo génico, frecuencias alélicas
3. **El equilibrio de Hardy-Weinberg** - Principio matemático, 5 condiciones, ecuación p² + 2pq + q² = 1
4. **Selección natural** - Tipos (direccional, estabilizadora, disruptiva), ejemplo de las polillas del abedul
5. **Deriva genética** - Efecto fundador, efecto cuello de botella
6. **Flujo génico (migración)** - Movimiento de genes entre poblaciones
7. **Mutaciones** - Tipos, importancia como fuente de variación genética
8. **Especiación y microevolución** - Especiación alopátrica y simpátrica, pinzones de Darwin
9. **Ejemplos reales de microevolución** - Pinzones de Darwin, resistencia a antibióticos, moscas de la fruta
